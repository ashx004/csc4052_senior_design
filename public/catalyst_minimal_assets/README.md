# Catalyst — Minimal UI Asset Kit

A soft, college-oriented minimalist icon set inspired by your Catalyst Discover page. No characters or anime.

- `svg/outline/`: 24×24 transparent SVG outline icons.
- `svg/tiles/`: 64×64 rounded pastel tile SVG icons.
- `png/outline/`: 96×96 transparent PNG exports.
- `png/tiles/`: 192×192 PNG exports with pastel tile backgrounds.
- `svg/score-ring-example.svg`: a **static sample only**; build the live score dynamically in React/CSS/SVG.

## Palette
- Main ink: `#29283B`
- Warm background: `#FBFAF8`
- Cream tile: `#F4F1ED`
- Lavender tile: `#EDEAF5`
- Light border: `#E6E2DF`
- Muted text: `#6F6B7A`
- Soft rose alert: `#F8EEEE`
- Score highlight: `#E8999A`

Use UI-native text, interactive buttons, card surfaces and badges instead of flattening them into images. The icons are standalone assets.
